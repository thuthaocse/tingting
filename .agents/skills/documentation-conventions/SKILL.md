# Documentation conventions

Write all repository documentation in English, including headings, prose, link labels, table text, and illustrative examples. Translate existing non-English documentation when editing it, preserving its technical meaning, commands, paths, identifiers, and links.

The application's product language remains Vietnamese. Use English translations when describing UI labels in documentation; do not change application strings as part of documentation translation.

Before committing documentation, review the changed files for untranslated prose and broken Markdown links. Follow the repository's commit-conventions skill for commits.
