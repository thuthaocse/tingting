# Commit conventions

Use `type(scope): description` as the commit subject. Choose `feat` for new features, `fix` for fixes, or `refactor` for restructuring that preserves behavior. Use a concise feature or area as the scope and a short, plain-language description of the change.

Examples:

- `feat(groups): add expense sharing`
- `fix(auth): preserve the return link`
- `refactor(balances): simplify debt calculation`

When a commit includes several related changes, choose the scope and type that best describe its overall purpose. Follow explicit user instructions for the contents and authorization of commits, history rewrites, and pushes.
